# robosys202x

ロボットシステム学の授業で使用する練習用リポジトリです。

## plusコマンド

標準入力から読み込んだ数字を足し合わせ、その合計を出力するPythonプログラムです。

### 使用方法

以下のコマンドで実行します。

```bash
seq 5 | ./plus
```

実行結果

```text
15
```

### 必要なソフトウェア

* Python 3

### テスト環境

* Ubuntu
* GitHub Actions

### テスト結果

GitHub Actionsを利用して自動テストを実施しています。

テストが成功するとGitHub上に緑色のチェックマークが表示されます。
